# Write a Survey（P5 规划）

当前尚不能自动生成跨论文综述。P5 计划支持：

```powershell
repro-forge write-survey --query "efficient transformers" --output survey.md
```

该命令只有在 artifact repository、语义索引、知识图谱和引用校验全部实现后
才会成为可运行接口。当前可使用 [Paper Reading](../user-guide/paper-reading.md)
逐篇生成笔记；未来行为见 [P5 实施规划](../P5-IMPLEMENTATION-PLAN.md)。
